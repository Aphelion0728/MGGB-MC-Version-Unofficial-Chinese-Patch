# MDF资源工具

汉化 ROM 兼容说明：

写回 `block_230.gbc` 时，工具会保留汉化 ROM 正文，并自动恢复内置模拟器
需要的原版识别头（标题、头部校验和、全局校验和）。用户放入 `CHS ROM` 的
原始文件不会被改写。若仍然白屏，则说明汉化补丁修改了模拟器依赖的程序代码，
需要进一步制作基于原版布局的 IPS/BPS 补丁。
工具可以放在任意位置运行；独立 EXE 放在游戏根目录时，会自动把地址栏设为 EXE 所在目录。也可以在地址栏选择包含 `windata` 文件夹的游戏根目录。

## 首次制作 EXE

在已安装 Python 3.10+ 的 Windows 电脑上双击 `build_MDF资源工具.bat`。脚本会安装 PyInstaller，并生成 `dist\MDF资源工具.exe`。把这个 EXE 复制到游戏根目录即可分发使用。

## 按钮功能

- **解包 alldata.bin**：先自动备份原文件到 `Buckup\年月日_时分秒\alldata.bin`，再把分块提取到 `Extracted\alldata.bin`。第 230 块会解码为 `block_230.gbc`，可直接替换为汉化 ROM；其余分块保存为原始 `block_NNN.mdf`，保证能够无损回写。
- **解包 alldata.psb.m**：自动备份后提取到 `Extracted\alldata.psb.m\resource.mdf`。当前 PSB 卷的运行时密钥尚未固定，因此采用原始 MDF 保存方式，可修改后无损回写。
- **重打包并写回资源**：再次自动备份，然后读取 `Extracted` 中的松散文件，重建并写回 `windata\alldata.bin`；如果存在 `resource.mdf`，同时写回 `alldata.psb.m`。第 230 块的 `.gbc` 会自动压缩、加密并保持原分块容量。
- **恢复备份**：选择 `Buckup` 中最新的一次备份，恢复其中存在的资源文件。

## 注意

请在重打包前退出游戏。工具默认不删除松散文件；重打包会覆盖游戏资源，但覆盖前一定会建立新的备份。第 230 块汉化 ROM 已使用 64 字节循环 XOR 密钥验证；已验证的汉化 ROM 保留自身全局校验字段 `17 B7`，不会改动 `CHS ROM` 中的原始文件。其他 MDF 分块保留原始加密块，避免错误解密。
