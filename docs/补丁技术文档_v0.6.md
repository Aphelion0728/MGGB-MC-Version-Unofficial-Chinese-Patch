# MGS_BC2 汉化补丁技术文档（v0.6）

## 1. 补丁组成

0.6 补丁由两部分组成：

1. `MGS MC2 Bonus Content.exe`：内置模拟器兼容层和已验证的快捷键/菜单入口修正。
2. `windata\alldata.bin`、`windata\alldata.psb.m`：GBC ROM、启动器文本图集、字体、提示框和制作人员名单等资源。

补丁不包含完整游戏、Steam DLL、原始 ROM 或原版备份。用户必须拥有正版《合金装备 大师合集 Vol.2》特典包。

## 2. alldata.bin 的 MDF 结构

`alldata.bin` 是按 `0x800` 字节对齐的 MDF 分块卷，不是普通 ZIP。每个块以以下头部开始：

```text
偏移 +0x00：mdf\0
偏移 +0x04：little-endian uint32，逻辑解压长度
偏移 +0x08：压缩/加密 payload
```

分块跨度由当前 MDF 头到下一个 MDF 头的距离决定，回包时必须保持原跨度和后续块偏移。第 230 块是内置模拟器读取的 4 MiB GBC ROM：

```text
ROM block offset: 0x0DB20000（229853184）
ROM block span:   1474560 bytes
ROM logical size: 4194304 bytes
```

## 3. GBC ROM 编码链

第 230 块的编码顺序为：

```text
4 MiB ROM -> zlib -> 64 字节循环 XOR -> MDF payload
```

64 字节 XOR 密钥：

```text
1124fa5f5ab36ae83cc359efd477b063
09d5c1c63fdc75ad474fdc5424f753ed
16fa23d1e91eeeb02dac32b6d67cd2b7a
6ff601a53c40a3cc16989ffcfc54643
```

解码公式：

```python
decoded[i] = payload[i] ^ key[i % 64]
```

重打包时压缩流必须小于 `ROM block span - 8`，余下空间用原始填充保持块大小不变。工具会对新块执行 XOR 解码和 zlib 回读，确认回读 ROM 与输入 ROM SHA-256 完全一致。

## 4. 模拟器兼容层和快捷键

汉化 ROM 的首 bank 发生了代码和指针位移，原版模拟器的全量覆盖表会覆盖汉化 ROM 的运行路径。当前兼容层只启用已经验证的 Mode1 Entry 5、6、7、8，并关闭 Entry 1～4 和 Entry 9～73。

快捷键的工作链为：

```text
键盘 Q / E 或手柄左右扳机
    -> 启动器/模拟器输入映射
    -> 内置模拟器菜单入口
    -> Codec 或装备栏页面
```

补丁不把 Q/E 当作普通 ROM 键盘输入硬编码，而是修正模拟器使用的入口表和 ROM 地址映射；这样可以保留原版暂停菜单和手柄扳机行为。

## 5. 文本图集和字体

启动器文本图集来自：

```text
assets\launcher\启动器英文文字图集_原始分辨率.psd
assets\launcher\启动器文字图集_第四十三版_槽位映射.json
```

PSD 用于编辑启动器的位图文本，槽位映射 JSON 用于把英文资源槽替换成中文图块。游戏内提示框和制作人员名单使用 PSB 位图字体资源。中文页由阿里巴巴普惠体 24px 统一生成，并保持统一基线、字面框和字宽，避免中文字符使用日文字形回退。

字体修改后必须同时检查：

- `code` 映射中是否存在所有中文字符；
- 图集页是否随 PSB 一起更新；
- 资源索引中的字体路径是否仍为 `system/font/title_sansserif_medium65_24pt.psb.m`；
- 提示文本的 `恢复`、`默认`、`设置` 等新增字符是否能从已部署资源中提取出来。

## 6. 提示框资源

提示文本位于 `system/config/notice.psb.m`。0.6 版本包含恢复默认设置、删除存档、退出游戏、关闭数字原声音乐等提示的简体中文文本。文本资源更新流程：

1. 修改解包 JSON 的 `eng` 字段。
2. 用 `PsBuild.exe` 重新编译 PSB。
3. 用 `PsbResourceReplace.exe` 替换 `system/config/notice.psb.m`。
4. 从新 `alldata.bin` 提取提示资源并反编译核对。

## 7. 资源替换命令模板

资源替换工具的命令行格式：

```text
PsbResourceReplace.exe replace <new-raw> <source-bin> <source-index> <key-prefix> <resource-name> <out-bin> <out-index>
```

当前 MDF 索引前缀：

```text
25G/xpvTbsb+6
```

替换字体的示例：

```powershell
src\csharp\PsbResourceReplace\bin\Release\net48\PsbResourceReplace.exe replace `
  working\font_rebuild_v3.psb `
  windata\alldata.bin windata\alldata.psb.m `
  25G/xpvTbsb+6 `
  system/font/title_sansserif_medium65_24pt.psb.m `
  working\alldata_font_complete.bin `
  working\alldata_font_complete.psb.m
```

## 9. 风险和边界

- `alldata.psb.m` 是运行时索引卷，未知部分必须原样保留，不得按第 230 块 ROM 的 XOR 密钥处理。
- 资源替换前必须退出游戏，避免文件锁和模拟器缓存造成误判。
- 任何 EXE、资源卷或 ROM 哈希不匹配时，工具应停止写入并保留备份。
- 未验证的模拟器入口表项不得重新启用；这会导致白屏、菜单错位或启动后闪退。
- Git 仓库不提交完整游戏目录、`windata` 原始数据卷、ROM、`Extracted`、`Buckup` 和 `working` 临时产物。完整 0.6 ZIP 作为 GitHub Release 资产发布。
