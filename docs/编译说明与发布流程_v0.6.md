# MGS_BC2 汉化工具编译说明与发布流程

本文对应《合金装备 大师合集 Vol.2》特典包非官方简体中文补丁 0.6。仓库保存可公开的工具源码、构建脚本、启动器文本图集源文件和技术资料，不包含完整游戏、原始 ROM、原版 `windata` 数据卷或 Steam 文件。

## 1. 环境

- Windows 10/11 x64
- Python 3.10 或更高版本
- .NET Framework 4.8 Developer Pack
- Visual Studio 2022、Build Tools 2022 或 .NET SDK
- Git
- Photoshop 或其他能够正确打开 PSD 的编辑器（仅修改文本图集时需要）

安装 Python 依赖：

```powershell
py -3 -m pip install -r requirements.txt
```

## 2. 仓库结构

```text
src/python/          三个 Python GUI 工具源码
src/csharp/          PSB 资源替换、资源添加和图集工具源码
tools/               构建、字体、诊断和维护脚本
tools/FreeMote/      构建 C# 工具及 PSB 所需的第三方运行时
assets/launcher/     启动器文本图集 PSD 与槽位映射
docs/                使用说明和补丁技术文档
```

`working/`、`release/`、游戏数据卷、ROM 和解包产物均由 `.gitignore` 排除。

## 3. 编译 Python 工具

在仓库根目录执行：

```powershell
py -3 -m PyInstaller --noconfirm --clean "tools/MDF资源工具.spec"
py -3 -m PyInstaller --noconfirm --clean "tools/MGS逻辑解包工具.spec"
py -3 -m PyInstaller --noconfirm --clean "tools/GBC汉化兼容补丁.spec"
```

也可以分别运行：

```text
tools/build_MDF资源工具.bat
tools/build_MGS逻辑解包工具.bat
tools/build_GBC汉化兼容补丁.bat
```

输出文件：

```text
dist/MDF资源工具.exe
dist/MGS逻辑解包工具.exe
dist/GBC汉化兼容补丁.exe
```

源码直接运行示例：

```powershell
py -3 "src/python/MDF资源工具.py"
```

## 4. 编译 C# 资源工具

三个项目目标框架均为 .NET Framework 4.8。项目文件通过相对路径引用 `tools/FreeMote/FreeMote.dll` 和 `FreeMote.Psb.dll`。

```powershell
dotnet build "src/csharp/PsbResourceAdd/PsbResourceAdd.csproj" -c Release
dotnet build "src/csharp/PsbResourceReplace/PsbResourceReplace.csproj" -c Release
dotnet build "src/csharp/LauncherAtlasRebuild/LauncherAtlasRebuild.csproj" -c Release
```

输出位于各项目的 `bin/Release/net48/`。FreeMote 是第三方组件，许可证原文位于 `tools/FreeMote/FreeMote.LICENSE.txt`；发布或再分发其二进制文件时必须保留该许可证。

## 5. 启动器文本图集

可编辑源文件：

```text
assets/launcher/启动器英文文字图集_原始分辨率.psd
assets/launcher/启动器文字图集_第四十三版_槽位映射.json
```

图集维护脚本位于 `tools/layout_chinese_text_atlas.py`。该脚本保留了本项目的槽位、字号、基线和布局规则；运行前需要按本机目录准备输入 PSD、映射 JSON 和目标输出目录。不要把包含游戏原始资源的工作目录提交到仓库。

## 6. 字体资源维护

提示框和制作人员名单使用 PSB 位图字体。维护时应使用阿里巴巴普惠体 Medium，并保持当前项目验证过的 24 px 字号、统一基线和字符单元。字体文件不随仓库发布，需自行按字体提供方许可取得并放入本地工作目录。

相关脚本：

```text
tools/prepare_notice_font_chars.py
tools/extend_notice_font.py
tools/preserve_font_fallback_glyphs.py
```

这些脚本处理从正版游戏中自行提取的 PSB JSON 和字体图集。运行前应检查脚本顶部的输入、输出路径常量并指向本地 `working/` 目录。生成后使用：

```powershell
tools/FreeMote/PsBuild.exe -v 4 -p win -o output.psb input.psb.m.json
```

再通过编译后的 `PsbResourceReplace.exe` 写入工作副本。每次替换后都要重新提取并核对字符映射、图集页、基线和 SHA-256。

## 7. 发布前检查

1. 退出游戏和启动器，避免资源文件被锁定。
2. 只在工作副本中替换 EXE、`windata/alldata.bin` 和 `windata/alldata.psb.m`。
3. 回读 GBC ROM、提示框、字体、制作人员名单和启动器图集，确认与候选输入一致。
4. 测试 Q/E、手柄左右扳机、暂停菜单、恢复默认设置、删除存档和退出游戏提示。
5. 对最终三个文件及 ZIP 计算 SHA-256。
6. 在干净安装上覆盖测试，确认可以启动、进入游戏并正常退出。
7. 仅把最终 ZIP 上传为 GitHub Release 附件，不把游戏数据卷或 ROM 提交到 Git 历史。
